# Project roadmap

This page tracks portfolio projects. A project moves from Planned to In progress only when implementation starts, and to Completed only after code, usage instructions, and tests or evaluation are documented.

## 1. Python Foundations
- **Area:** Python programming and problem solving
- **Status:** Planned
- **Planned scope:** small command-line utilities, input validation, functions, file handling, and unit tests.
- **Completion evidence:** source code, examples, and tests.

## 2. HyBaLF-LightGBM
- **Area:** Machine learning research
- **Status:** Research direction; implementation and results not yet documented here.
- **Planned scope:** reproducible preprocessing, feature selection, Bayesian hyperparameter optimization, LightGBM training, and baseline comparisons.
- **Completion evidence:** dataset citation, experiment configuration, metrics, feature-importance analysis, and reproducible instructions.

## 3. Python Blockchain
- **Area:** Blockchain and cryptography fundamentals
- **Status:** Planned
- **Planned scope:** block structure, SHA-256 digest linking, simple transaction records, chain validation, and tamper-detection examples.
- **Completion evidence:** runnable demo, tests, and limitations.

## 4. RAG Document Assistant
- **Area:** Generative AI
- **Status:** Planned
- **Planned scope:** document ingestion, chunking, embeddings, retrieval, and answer generation with source references.
- **Completion evidence:** setup instructions, evaluation examples, and limitations.

## Working principles
- Do not publish secrets, API keys, credentials, or private datasets.
- Cite external datasets and research sources.
- Report measured results only; do not invent performance claims.
- Document limitations and known issues.
